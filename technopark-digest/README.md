# Дайджест по технопаркам мира → Telegram

Каждое утро собирает новости о технопарках, научных парках, инновационных
районах и ОЭЗ и присылает их в Telegram одним сообщением в едином формате.

## Формат карточки

```
1. Заголовок новости
🏢 Технопарк: Cambridge Science Park (Великобритания 🇬🇧)
📌 Что сделали: суть в 1–2 предложениях
🔗 ссылка на источник
```

Площадка и страна определяются правилами (словарь известных парков + шаблоны
вида «X Science Park», «технопарк "X"», «ОЭЗ "X"»). Если площадку определить
нельзя — пишется «не определён», а не выдуманное название.

## Запуск — вариант А: на своём компьютере

GitHub для этого не нужен.

```bash
cd technopark-digest
pip install -r requirements.txt

cp .env.example .env        # и вписать туда токен и chat_id
python3 digest.py --ping    # проверка связи: должно прийти "Связь есть"
python3 digest.py           # первый настоящий выпуск
```

Файл `.env` лежит в `.gitignore` — секреты в репозиторий не уедут.

Ежедневный запуск в 08:00 через `cron` (macOS, Linux):

```bash
crontab -e
# добавить строку, подставив свой путь:
0 8 * * * cd /путь/к/technopark-digest && /usr/bin/python3 digest.py >> digest.log 2>&1
```

На Windows то же самое делается через «Планировщик заданий» → создать задачу →
ежедневно в 08:00 → действие `python.exe`, аргумент `digest.py`.

## Запуск — вариант Б: GitHub Actions (без терминала)

**1.** Создать бота: [@BotFather](https://t.me/BotFather) → `/newbot`.

**2.** Узнать chat_id: [@userinfobot](https://t.me/userinfobot). Затем нажать
`/start` у своего бота, иначе он не имеет права писать первым.

**3.** Вписать секреты:
[Settings → Secrets → Actions → New secret](https://github.com/funderberger/fot-calculator/settings/secrets/actions/new)

| Имя секрета | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из BotFather |
| `TELEGRAM_CHAT_ID` | ID из шага 2 |

**4.** Проверить, не дожидаясь утра:
[Actions → technopark-digest → Run workflow](https://github.com/funderberger/fot-calculator/actions/workflows/technopark-digest.yml)

Дальше дайджест приходит сам в 08:00 МСК.

Важно: GitHub запускает задачи по расписанию только из главной ветки
(`main`). В другой ветке workflow не появится в списке Actions и не будет
срабатывать по утрам.

## Предпросмотр без отправки

В [Actions → technopark-digest → Run workflow](https://github.com/funderberger/fot-calculator/actions/workflows/technopark-digest.yml)
есть галочка «Предпросмотр». С ней выпуск печатается в лог прогона и никуда
не отправляется, а новости не помечаются прочитанными — удобно, чтобы
посмотреть на подборку перед настоящей рассылкой.

## Отладка

```bash
python3 digest.py --dry-run     # выдача в консоль, ничего не отправляется
python3 digest.py --no-enrich   # не ходить за описаниями на сайты (быстрее)
python3 tests.py                # самопроверка, сеть не нужна
```

## Файлы

| Файл | Назначение |
|---|---|
| `feeds.yml` | источники, ключевые слова, глубина выборки, лимит новостей |
| `digest.py` | сбор, фильтрация, дедупликация, отправка |
| `extract.py` | разбор новости на поля: площадка, страна, суть |
| `tests.py` | самопроверка, гоняется в CI перед каждой отправкой |
| `seen.json` | уже отправленные ссылки, хранятся 30 дней |
| `.env` | токен и chat_id для локального запуска (в `.gitignore`) |
| `../.github/workflows/technopark-digest.yml` | расписание |

## Настройки

**Время.** Cron в GitHub Actions всегда в UTC. В workflow стоит `0 5 * * *` —
это 08:00 МСК. 09:00 МСК → `0 6 * * *`; только будни → `0 5 * * 1-5`.
Бесплатные раннеры в часы пик стартуют с задержкой до ~15 минут.

**Объём.** `max_items` в `feeds.yml` — сколько новостей в выпуске (сейчас 10).
`lookback_hours: 26` — глубина выборки с запасом на опоздание раннера.

**Источники.** Добавляй в `feeds.yml`. Если у сайта нет RSS, работает приём
через Google News: `https://news.google.com/rss/search?q=site:домен+when:7d`.
Недоступные фиды пропускаются, их число видно в подвале сообщения.

**Фильтр.** Новость проходит, если в заголовке или описании есть хоть одно
слово из `keywords`. Фиды из списка `trust_all` идут без фильтра.
